# Day 22 — Multi-Agent Research Assistant

## Linkific AI & ML Internship

A simple multi-agent AI workflow built using **LangGraph** and **Groq LLM**.

The system divides the research task among multiple specialized AI agents.

---

## Objective

The objective of Day 22 is to understand:

- Agent Roles
- Agent Communication
- Shared State
- Workflow Planning
- Multi-Agent Systems
