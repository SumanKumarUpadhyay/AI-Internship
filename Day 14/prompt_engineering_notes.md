# Prompt Engineering Notes

## What is an LLM?

A Large Language Model (LLM) is an AI model trained on large amounts of text data to understand and generate human-like language.

Examples:

- ChatGPT
- Gemini
- Claude
- Llama

---

## What is Prompt Engineering?

Prompt Engineering is the process of writing clear and detailed instructions to obtain better responses from AI models.

---

## Tokens

Tokens are small units of text processed by an LLM.

Example:

"I love AI"

Tokens:

- I
- love
- AI

---

## Temperature

Temperature controls the creativity of AI.

- 0.0 → More accurate
- 0.5 → Balanced
- 1.0 → More creative

---

## Prompt Types

- Zero-shot Prompt
- One-shot Prompt
- Few-shot Prompt
- Chain-of-Thought Prompt

---

## API Key

An API Key is a unique secret key used to access AI services securely.

Example:

OpenAI API Key

Google Gemini API Key

Groq API Key

Hugging Face API Key
