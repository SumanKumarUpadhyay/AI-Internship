# 🤖 LangGraph AI Assistant

A simple AI Assistant built using **LangGraph, Groq LLM, Wikipedia, and Streamlit**.  
The project demonstrates how an AI workflow can be designed using **Nodes, Graphs, State, Conditional Routing, Loops, Memory, and Error Handling**.

This project was developed as part of **Day 19 of the Linkific AI & ML Internship**.

---

## 🎯 Project Objective

The objective of this project is to understand and implement a basic **LangGraph workflow** where a user asks a question, relevant information is retrieved using Wikipedia, an LLM generates a report-style response, and conversation history is maintained using memory.
