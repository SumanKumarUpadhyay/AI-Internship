# Day 26 — Responsible AI Summary

## Overview

Responsible AI means designing, developing, and deploying AI systems in a way that is fair, safe, transparent, privacy-aware, and accountable.

AI systems should not be evaluated only by their accuracy. Their impact on users and society should also be considered.

---

## Key Responsible AI Principles

### 1. Fairness

AI systems should avoid unfair discrimination and should be tested for possible bias.

### 2. Privacy

Personal and sensitive information should be collected and processed responsibly.

### 3. Accuracy

AI-generated information should be validated when accuracy is important.

### 4. Hallucination Prevention

AI systems should avoid presenting unsupported or false information as facts.

### 5. Transparency

Users should understand when and how AI is being used where appropriate.

### 6. Security

AI applications should protect user data, API keys, credentials, and system resources.

### 7. Human Oversight

Humans should remain involved in important or high-impact decisions.

### 8. Monitoring

AI systems should be continuously monitored after deployment.

### 9. Accountability

There should be clear responsibility for managing, monitoring, and improving AI systems.

---

## Common AI Risks

| Risk | Example | Prevention |
|---|---|---|
| Bias | Unfair predictions | Bias testing |
| Hallucination | False information | Verification and grounding |
| Privacy | Exposing personal data | Data protection |
| Security | Exposed API key | Environment variables |
| Misuse | Harmful application | Access control and monitoring |
| Lack of transparency | User does not know AI is being used | Clear communication |
