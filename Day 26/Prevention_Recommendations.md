# Day 26 — Responsible AI Prevention Recommendations

## Objective

The purpose of this document is to define practical steps that can help prevent common Responsible AI problems such as bias, hallucination, privacy issues, security risks, and unfair decisions.

---

## 1. Preventing AI Bias

### Recommended Actions

- Review training data before using it.
- Identify possible bias in historical data.
- Remove or reduce inappropriate biased features where possible.
- Test model performance across relevant groups.
- Perform fairness evaluation before deployment.
- Continuously monitor model outcomes.
