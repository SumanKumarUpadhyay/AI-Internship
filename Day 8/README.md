# Loan Approval Prediction using Machine Learning

## Objective
To predict whether a loan application will be approved using Machine Learning classification algorithms.

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

## Best Model
Decision Tree

## Accuracy Comparison

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 90.98% |
| Decision Tree | 98.59% |
| Random Forest | 98.01% |
| KNN | 92.86% |

## Dataset
Loan Prediction Dataset (614 records)

## Libraries
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Outcome
Decision Tree achieved the highest accuracy and was selected as the final model.
